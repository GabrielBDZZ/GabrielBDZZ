### Sobre mim

Desenvolvedor **Fullstack e de IA** na **União B F Toys** e **Chief AI Officer** na **SeaTech**, programando profissionalmente desde 2022. Gosto de pegar um processo manual e transformar em produto: API bem desenhada, front rápido, deploy automatizado e, cada vez mais, um agente de IA fazendo o trabalho pesado.

<table>
  <tr>
    <td width="33%" valign="top">

    </td>
    <td width="33%" valign="top">
      <h4>🧩 Produto fullstack</h4>
      SaaS multi-tenant de ponta a ponta: <b>React + TypeScript</b> no front, <b>Node/Express + Prisma</b> ou <b>FastAPI</b> no back, autenticação, pagamentos e CI/CD.
    </td>
    <td width="33%" valign="top">
      <h4>📊 Dados & integrações</h4>
      ETL de ERPs (PostgreSQL, MySQL, Firebird), APIs com OAuth 2.0 (Conta Azul, Asaas, Slack), dashboards de BI e modelos de ML com <b>scikit-learn</b>.
    </td>
